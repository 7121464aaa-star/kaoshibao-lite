# 考试宝自用版 · 数据模型与判分规则（M0 契约）

> 本文档是全项目的**数据契约**。后续 M1~M5 的所有功能（导入、错题本、模拟考试、同步）都必须遵守这里的字段与判分规则。改动本文档 = 改动契约，需同步改代码与迁移脚本。

## 1. 版本信息

- 当前模型版本：`v1`
- 存储：浏览器 IndexedDB，库名 `ksb-lite`，对象仓库（object store）见 §5。
- 导出/同步单位：整个库的 JSON 快照（含所有 store），见 §5.4。

## 2. 题型枚举

| 常量 | 中文名 | 判分方式 | 选项 | 答案字段 |
|---|---|---|---|---|
| `single` | 单选题 | 自动 | 多选一 | `answer: "A"`（选项键） |
| `multiple` | 多选题 | 自动（全对才得分） | 多选多 | `answer: ["A","C"]` |
| `judge` | 判断题 | 自动 | 固定 正确/错误 | `answer: true / false` |
| `fill` | 填空题 | 自动 | 无 | 按空给出可接受答案集，见 §3.4 |

题型中文名映射（用于展示）：`single=单选题，multiple=多选题，judge=判断题，fill=填空题`。

## 3. 题目对象（Question）

```jsonc
{
  "id": "唯一id（全局，跨题库不重复）",
  "bankId": "所属题库id",
  "type": "single|multiple|judge|fill",
  "stem": "题干文本（支持换行；填空题用 （　）或 __ 标记空位）",
  "options": [ {"key":"A","text":"选项文本"}, ... ],  // 仅 single/multiple 有；judge 固定不用存
  "answer": "见 §2 表格与 §3.4",
  "analysis": "解析（可为空字符串）",
  "chapter": "章节名（可选）",
  "createdAt": "ISO 时间",
  "source": "来源备注（可选，如：考试宝导出/人工录入）"
}
```

### 3.1 单选 `single`
- `options` ≥ 2 项，键为大写字母 `A` 起依次递增。
- `answer` = 正确选项的键，如 `"B"`。
- 判分：用户所选键 `=== answer`。

### 3.2 多选 `multiple`
- `answer` = 正确键数组 `["A","C","D"]`，建议按字母序存。
- 判分：**全选对方得分**；漏选、多选、选错均判错。不给部分分。
- 反馈中提示：若只漏选，提示"漏选了 X"；若多选，提示"多选了 X"（可选增强）。

### 3.3 判断 `judge`
- 界面固定渲染两个选项：`正确 / 错误`（键 `T/F`，不入库）。
- `answer` = `true`（正确）或 `false`（错误）。
- 判分：用户所选布尔值 `=== answer`。

### 3.4 填空 `fill`
- 空位标记：题干中的 `（　）`（全角括号含空格）、`__`（两个及以上下划线）、`【　】`。
- 空位数 = 上述标记出现次数；无标记时按 1 个空处理。
- `answer` = **按空排列的二维数组**，每空给出一个可接受答案列表：
  ```json
  "answer": [ ["水星"], ["义勇军进行曲", "义勇军军歌"], ["氮气","氮","N2"] ]
  ```
- 判分规则（每空）：
  1. 用户输入去除首尾空白；
  2. 全角字符转半角、统一大小写（`KSB.norm`）；
  3. 与该空任一可接受答案归一化后相等即判该空对；
  4. **全部空对才判对**，否则判错并在反馈里指出错在哪一空（第 N 空）。
- 兼容简写：导入历史数据时，若 `answer` 是字符串数组 `["水星","水"]`（旧式单空格式），自动转成 `[["水星","水"]]` 再入库。

### 3.5 题型范围（轻量版）

- 自轻量版起，**简答题（`short`）与手动自评已移除**：应用仅支持 `single / multiple / judge / fill` 四种自动判分题型。
- 兼容策略：加载旧题库或导入文本时遇到 `short` 一律**过滤/跳过并提示**，不计入练习与统计。

## 4. 题库对象（Bank）

```jsonc
{
  "id": "唯一id",
  "name": "题库名",
  "description": "简介（可选）",
  "createdAt": "ISO 时间",
  "updatedAt": "ISO 时间"
}
```

- 题库与题目 1:N；题目通过 `bankId` 归属。
- 删除题库 = 连带删除其全部题目（事务内完成）。

## 5. IndexedDB 设计（库名 `ksb-lite`）

### 5.1 对象仓库

| store | keyPath | 索引 | 说明 |
|---|---|---|---|
| `banks` | `id` | — | 题库 |
| `questions` | `id` | `bankId` | 题目 |
| `wrong` | `qid` | `bankId` | 错题本（按题一条，聚合错次） |
| `stars` | `qid` | `bankId` | 收藏（M2 起用，条目 `{qid, bankId, starredAt}`） |
| `settings` | `k` | — | 键值设置：条目 `{k, v}`；键：`lastBackupAt`（M3）、`sync.username/sync.token/sync.gistId/sync.lastPushAt/sync.lastPullAt`（M4 云同步）。**sync.token 只存本机，绝不写入导出快照/云端** |
| `history` | `id` | `bankId, type` | 练习/考试记录（M2 起用） |
| `snapshots` | `id` | — | 内部 store（M4）：一键同步冲突自动快照 `{id, kind:'push'|'pull'|'cloud', at, note, snapshot}`，保留最近 N=5，仅本机，不导出 |

- 练习"记录保留时间"：本产品**永久保留**（这是无 VIP 复刻的意义之一）。
- `history` 记录可含可选字段 `chapter`（该场练习应用的章节筛选，M3 起记，向前兼容）。

### 5.2 错题本条目（wrong）

```jsonc
{
  "qid": "题目id（主键，一道题一条）",
  "bankId": "所属题库",
  "wrongCount": 3,          // 累计答错次数
  "lastWrongAt": "ISO 时间",
  "lastUserAnswer": "最近一次错误作答的序列化摘要（用于复盘，可为空）"
}
```

- 答错 → `wrongCount+1`、更新 `lastWrongAt`。
- 答对**不**自动移出错题本；只有用户在错题本手动"标记已掌握"才删除（M2 实现）。

### 5.3 判分结果统一结构（JS 内）

```js
{ state: 'correct' | 'wrong',   // 简答自评已移除（manual 不再使用）
  expected: '人类可读的正确答案文本',
  detail: '补充说明（如漏选了…/第2空错误）' }
```

### 5.4 导出/同步快照（同步、备份共用同一格式）

```jsonc
{
  "app": "kaoshibao-lite",
  "modelVersion": "v1",
  "exportedAt": "ISO 时间",
  "data": {
    "banks": [ ... ],
    "questions": [ ... ],
    "wrong": [ ... ],
    "stars": [ ... ],
    "settings": [ ... ],
    "history": [ ... ]
  }
}
```

- 备份/恢复（M3 UI，设置页）：**导出** = 下载上述 JSON 快照文件；**恢复** = 校验 `app` 后**整体替换业务 store**（事务清空再写入）。恢复前应用会自动下载一份当前数据备份，供反悔还原。
- 导入合并策略（M1 实现）：按 `id` 去重；id 冲突时**新导入的覆盖旧的**。
- **M4 起（云同步/备份共用）**：导出快照前**剥离 settings 敏感键**（`sync.token`）；导入/恢复/拉取时**忽略 settings 与 snapshots**（保留本机凭据与内部快照）。DB v3 新增 `snapshots` 内部 store。
- **M4 云同步（Secret Gist 中转）**：冲突策略=**后写覆盖 + 自动快照**——推/拉覆盖前先把"被覆盖方"内容存为本地自动快照（保留最近 N=5，可一键还原）；两端一致性用**业务内容比较**（banks/questions/wrong/stars/history 五个 store 的序列化），不用 exportedAt 时间戳（每次导出都变化，会误判冲突）。

## 6. 判分总则（所有模式统一调用）

1. 选择题/判断题/填空题：作答后**立即判分**（练习模式）或**交卷统一判分**（模拟考试，M2），结果规则完全一致。
2. 题型范围为单选/多选/判断/填空，全部自动判分（简答题已不支持）。
3. 正确率 = 已判题中判对数 / 已判题数 ×100%（未答不计入分母）。
4. 答错的题自动进入错题本（练习与考试都触发）。
