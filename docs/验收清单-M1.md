# M1 验收清单：题库管理 + 导入器 + 顺序/随机模式

> 验收方式：打开 `app/index.html`（双击可开）逐项验证；自动化测试记录见文末 §G。

## A. 题库管理（Tab：题库管理）
- [x] 新建题库（名称+简介），创建后**立即出现在列表**，并自动切换为当前刷题库
- [x] 列表显示：名称、简介、题数、创建日期
- [x] 点"刷题"→ 切换到该库并进入刷题页
- [x] 重命名（防呆：空名不生效）
- [x] 删除：二次确认，**级联删除**该库全部题目与错题记录，事务一致（无孤儿数据）
- [x] 删除当前练习中的库 → 自动回退到第一个剩余题库，界面不白屏

## B. 导入器（Tab：导入题库）
- [x] 三种源格式：段落文字（考试宝文字模式）/ CSV 表格 / JSON 题库，均可从文本粘贴或载入 .txt/.csv/.json 文件
- [x] 段落文字解析：题型自动识别 + 支持 题型: 前缀、A. B. 选项行、答案行、解析行；5 种题型全部正确（实测 5/5、0 错）
- [x] CSV：表头映射（题干/题型/选项A..H/答案/解析/章节），实测 4/4、0 错
- [x] JSON：数组 或 {bank:{name},questions:[…]}，实测 2/2、0 错；整库备份文件被识别并提示走"备份恢复"
- [x] 规范化：多选答案 ABD→数组、判断 对/错→布尔、填空 答案按 空位+变体 转二维数组（`["宪法","根本法"]`→`[["宪法","根本法"]]`）、选项字母键大写去重排序
- [x] 错误收集：逐题失败仍可导入成功的部分，预览表格展示前 10 道（#/题型/题干/答案）
- [x] 导入目标：新建题库 或 追加到已有题库；导入后自动切换到该库开始刷题
- [x] 三种格式各有"填入示例"一键演示 + 格式说明

## C. 练习模式
- [x] 顺序 / 随机模式切换；随机模式点"重新开始"会重新打乱（实测三种排列两两不同）
- [x] 切换模式/换库/重新开始会清空本次作答（带确认），判分、错题收录、答题卡、统计逻辑与 M0 一致（回归通过）
- [x] 空题库有引导文案，不白屏

## D. 工程性
- [x] `node tools/build-single.mjs` → `dist/考试宝自用版.html`（71.1 KB）
- [x] 单文件版双击可开：4 个 Tab、导入解析器、判分全部可用
- [x] 全程 0 控制台 JS 错误（自动化监听 error/unhandledrejection）
- [x] 数据模型契约无变更（导入器只是产出符合契约的 Question）

## E. 边界说明（已知、可接受）
- `.xlsx / .docx` 二进制不直接在浏览器解析 → 界面已引导"另存为 .txt/.csv(UTF-8) 或复制粘贴"（避免引入 MB 级第三方库；M5 导出辅助将直接产出 JSON，不受影响）
- CSV 请用 UTF-8 编码（Excel 另存时选择），GBK 会乱码——已在格式提示中说明
