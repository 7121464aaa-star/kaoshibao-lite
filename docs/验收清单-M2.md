## H. 修复记录
1. **模拟考试计时器一直空白 + 大量 "Script error."（真凶）**：`exam.js` 的 `updateExSheet` 引用 `#exSheetTitle`，
   但该标题 div 漏写了 `id` → 每次渲染/作答/计时开始都抛 TypeError 并中断 `setInterval` 创建。
   修复：`index.html` 补 `id="exSheetTitle"`。修复后计时与全流程 0 报错。
2. 简答题相关代码（grade/importer/ui/exam/stats/样例/契约文档）全部移除，导入遇到 short 会跳过并提示。
