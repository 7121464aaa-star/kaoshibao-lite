# M6 手机端使用指引：PWA 安装 + 数据搬运到手机

> 面向使用者（非技术向，照做即可）。配套验收清单：`docs/验收清单-M6.md`。
> 在线地址（与电脑在线版同源）：**https://7121464aaa-star.github.io/kaoshibao-lite/**
> 原则提醒：`file://` 离线双击版与 `https://` 在线版（含手机 PWA）的浏览器数据**互相隔离**，各自要搬运/导入一次。

---

## 0. 三分钟速览

| 目标 | 做法 | 结果 |
|---|---|---|
| 手机装一个可离线刷题的图标应用 | 手机浏览器打开在线地址 → 「添加到主屏幕 / 安装应用」 | 桌面出现「考试宝」图标，点开即应用 |
| 把电脑上的题库数据带到手机 | 电脑导出备份 JSON → 微信发到手机 → 应用内「从备份文件恢复」 | 手机出现「考研政治题库（马原+时政）」616 题 |
| 只带一个题库（不动手机现有数据） | 应用内「导入题库 → JSON」导入单库 JSON | 新增一个题库，其它数据保留 |
| 以后想两端持续同步 | 设置 → 云同步（Secret Gist） | 一键推送 / 拉取（需一次 token，见 §5） |

## 1. 需要准备的东西

- 手机浏览器（二选一）：
  - **安卓**：Chrome 或 Edge（推荐 Chrome）。
  - **苹果**：Safari（必须用 Safari 添加主屏幕）。
- 电脑上已有的两个数据文件（都在 `E:\浏览器下载\数据\outputs\`，不用重新生成）：
  1. `kaoshibao-lite-整库备份-考研政治20260905.json` —— **整库备份**（样例 20 题 + 考研政治 616 题，恢复=整体替换手机数据，推荐新手机首次用）
  2. `kaoshibao-bank-考研政治题库.json` —— **单库 JSON**（只含考研政治题库 616 题，导入=新增一个库，不覆盖手机已有数据）

> 想重新导出最新数据？电脑打开应用 → **设置 → 备份/恢复 → ⬇ 导出备份**，得到新的
> `kaoshibao-lite-备份-YYYYMMDD-HHMMSS.json`，用它替换上面的文件 1 即可。

## 2. 第一步：把数据文件传到手机（微信最方便）

### 2.1 电脑微信
1. 电脑微信 → 搜索并打开 **文件传输助手**（自己的聊天）。
2. 把上面要用的 json 文件（1 个或 2 个都行）**拖进聊天框发送**。

> 提醒：微信发送后**文件名保持不变、后缀必须是 `.json`**。若手机端收到后变成「xxx.json 副本」或后缀丢失，先在手机文件管理里重命名回 `xxx.json`（见 §6 常见问题）。

### 2.2 手机微信
- **安卓**：手机微信打开「文件传输助手」→ 点开收到的文件 → 右上角「… / 用其他应用打开」→ 选择**保存到手机**（一般存到「下载 Download」目录）。若微信问用哪个应用打开，选「文件/文档」类即可，关键是文件已保存到手机存储。
- **苹果**：手机微信打开该文件 → 点右上角「…」→ **「用其他应用打开」→「存储到"文件"」**（存到 iCloud 云盘或"我的 iPhone"均可），之后浏览器选文件时从"文件"App 里挑。

## 3. 第二步：安装 PWA（得到主屏幕图标）

1. 手机浏览器打开：**https://7121464aaa-star.github.io/kaoshibao-lite/**
2. 看到「📚 考试宝自用版」页面后：
   - **安卓 Chrome**：地址栏右侧或右上角 ⋮ 菜单 → **「安装应用」/「添加到主屏幕」** → 确认安装。
   - **安卓 Edge**：⋮ 菜单 → **「添加到手机」/「安装此站点」**。
   - **iPhone Safari**：底部**分享按钮（□↑）→ 「添加到主屏幕」→ 右上角「添加」**。
3. 回到主屏幕，出现**「考试宝」图标**（蓝底白字，带书本样式）→ 点开。
4. 验证点 ①：点开后是独立全屏应用（没有浏览器地址栏），且首次打开自动有 **「样例题库（20题）」**。

> 打不开 / 没有安装菜单？见 §6 常见问题 F1。

---

## 4. 第三步：把数据搬进手机（二选一）

### 方案 A：整库恢复（推荐：手机是新的 / 想要和电脑一模一样）
1. 在 PWA 里点底部/顶部导航 **设置** → 找到 **💾 备份 / 恢复**。
2. 点 **⬆ 从备份文件恢复** → 从手机文件里选 `kaoshibao-lite-整库备份-考研政治20260905.json`
   （安卓选"下载/Download"，苹果选"文件"里刚存的位置）。
3. 预览应显示：**题库 2 · 题目 636 · 错题 0 · 收藏 0 · 历史记录 0**，然后点 **「确认恢复（先自动备份当前数据）」**。
4. 页面自动刷新后，验证点 ②：顶部题库选择器出现两个库 —— **样例题库（20题）** 和 **考研政治题库（马原+时政）**。

> ⚠ 恢复=整体替换：手机 PWA 里现有的数据会被备份内容覆盖（首次安装只有样例，覆盖无损失；恢复前应用会自动下载一份当前数据备份防反悔）。

### 方案 B：单库导入（想保留手机现有数据，只加考研题库）
1. PWA 里进 **导入题库** 页签 → 源格式选 **JSON**。
2. 点 **⬆ 选择文件** 选 `kaoshibao-bank-考研政治题库.json`（或粘贴 JSON 全文）。
3. 解析预览应显示：**成功 616 道（单选 314 · 多选 202 · 判断 100），0 失败**。
4. 「新建题库名」若已自动填为「考研政治题库（马原+时政）」直接确认导入；若为空则手动填这个名字（旧版线上代码不会自动填名，手填即可，不影响数据；新版本已修复自动填名）。
5. 提示「已导入 616 道」后，验证点 ② 同上：选择器里出现该库。

## 5. 第四步（可选）：以后想两端自动同步 → 云同步

> 前提：你在 GitHub 已登录（电脑端 M4 已建仓库的账号 `7121464aaa-star`）。此功能**联调待用户实测**，正好用本次手机验证顺带完成。

1. **电脑端**（在线版或本地均可）：设置 → ☁️ 云同步 → 填 GitHub 用户名 `7121464aaa-star` 与 **Token（只勾 gist 权限）** → 保存 → **⬆ 推送到云端**（首次自动建 Secret Gist 并记住 ID）。
   - Token 生成：GitHub → Settings → Developer settings → Personal access tokens (classic) → 勾 **gist** → 生成后立即复制。**Token 只在浏览器里填，不要发给任何人 / 发到聊天。**
2. **手机端**：设置 → ☁️ 云同步 → 填**同一个用户名与同一个 Token** → 保存 → **⬇ 从云端拉取**。
3. 之后每次在电脑上做完题点「推送到云端」，手机点「从云端拉取」即同步；误覆盖可用「自动快照（最多 5 份）→ 还原」。

> 不想用云：永远可以用 §2–§4 的备份文件搬运，完全离线可用，无任何账号依赖。

## 6. 常见问题（手机端 FAQ）

| 编号 | 现象 | 处理 |
|---|---|---|
| F1 | 打开在线地址没有「安装/添加到主屏幕」入口 | 必须是 **https**（本地址已是）；安卓用 Chrome/Edge；**iPhone 必须用 Safari** 的「分享 → 添加到主屏幕」，微信内置浏览器没有安装入口（先在 Safari 打开） |
| F2 | 微信收到的文件打不开 / 后缀变成别的 | 在手机文件管理里确认是 `.json` 结尾并重命名（如 `xxx.json 副本` → `xxx.json`）；苹果需先「存储到文件」 |
| F3 | 恢复预览显示 0 题 | 选错文件（可能被微信改坏/截断）；回到电脑重新发送一次，或换方案 B 导入单库 JSON 验证 |
| F4 | 恢复后题库选择器里没有考研题库 | 确认预览步骤出现「题库 2 · 题目 636」再点确认；若只出现 1 个库，检查恢复的文件是否为整库备份（不是单库 JSON） |
| F5 | 「导入题库 → JSON」不自动填题库名 | 说明线上跑的是旧版代码：先确认已按 F1 打开的是最新页面（可刷新/稍后再试）；仍不自动填名就手动输入题库名，不影响判分/错题/收藏 |
| F6 | 手机断网后打不开 | PWA 首次在线打开后已缓存外壳，**飞行模式**下再开一次验证（应能正常刷题）；若从未成功在线打开过则需先联网一次 |
| F7 | 手机和电脑数据对不上 | 正常现象：两者是**独立存储**。每次在电脑新增/修改后，重新导出备份并再次恢复（或改用 §5 云同步） |
| F8 | 手机上恢复会丢掉我手机里已有的数据吗 | 方案 A 会（整体替换，但恢复前会自动下载当前数据备份）；方案 B 不会（只新增一个库） |
| F9 | iPhone 刷题时想横屏 | 应用为竖屏优先设计，个别页面可旋转属正常，不影响使用 |
| F10 | 忘记 Token / 想换手机 | Token 只存本机：换设备后重新填一次即可；数据若在云端，新设备拉取前先确认电脑端推送过最新数据 |
