# M0 验收清单：数据模型 + 20 题样例 + 判分最小闭环

> 验收方式：打开 `app/index.html`（可直接双击，无需服务器）逐项勾选。全部 ☐ 打勾即 M0 完成，进入 M1。

## A. 打开与数据
- [ ] 双击 `app/index.html` 能打开，无需任何服务/安装
- [ ] 自动载入"样例题库（20题）"，无手动导入动作
- [ ] 页面显示当前题库名、总题数 20、进度与正确率

## B. 题型与判分（判分是本产品硬性要求，逐类验证）
- [ ] **单选题**：点一个选项 → 立即显示 ✅正确 或 ❌错误 + 正确答案 + 解析
- [ ] **多选题**：勾选若干 → 点"提交本题"判分；全对才显示正确；漏选/多选显示错误并给出提示
- [ ] **判断题**：点"正确/错误" → 立即判分并显示正确答案
- [ ] **填空题**：输入后点"提交"判分；大小写/全半角不影响判断（如填"n2"与"N2"都算对）
- [ ] **简答题**：输入后出现"自评：判对 / 判错"，点选后计入统计（不自动判分）
- [ ] 判分后本题作答控件锁定，不能偷偷改答案

## C. 导航与答题卡
- [ ] 上一题 / 下一题可翻动全部 20 题
- [ ] 答题卡格子反映状态：未答 / 待判(多选未提交或简答未自评) / 答对(绿) / 答错(红)
- [ ] 点击答题卡任意格可跳转到对应题

## D. 统计与错题
- [ ] 顶部统计实时更新：已答 X/20、答对 a、答错 b、正确率 c%
- [ ] 答错的题自动进入"错题本"页签（含错次与最近错误时间）
- [ ] 同一题重复答错，错次累加
- [ ] 错题本条目显示题干摘要，能看清是哪道题

## E. 工程性
- [ ] 刷新页面后数据仍在（IndexedDB 持久化），不会每次重载样例
- [ ] 终端执行 `node tools/build-single.mjs` 产出 `dist/考试宝自用版.html`（单文件）
- [ ] 单文件版同样能双击打开、跑通上述 A~D 全部流程
- [ ] 文档《数据模型与判分规则.md》与代码实现一致（抽查题型字段与判分总则）

## F. 记录（非阻塞项）
- 本次验收发现的任何问题/建议 → 记入项目 `docs/BACKLOG.md`（范围外需求不进 M0）。
