# M11 验收清单 —— 背题模式（一直显示答案开关）

> 日期：2026-09 · 对应 docs/项目进度与交接.md §19 · 角标 M11
> 需求：加一个「显示答案」的开关方便背题 —— 开了就一直显示答案，不要一题一题作答才显示。

## A. 功能（已实现，见本机实测 ✅）

| # | 验收项 | 结果 |
|---|---|---|
| A1 | 刷题页工具条出现「👁 答案」开关，开启后按钮变「👁 答案·开」并高亮 | ✅ |
| A2 | 设置页「外观与刷题习惯」出现「背题模式：直接显示答案」开关，与工具条按钮同源同步 | ✅ |
| A3 | 开启后：**未作答**的选择题（单选/多选/判断）正确选项直接标绿 ✓、不可误点作答 | ✅（单 9 / 多 4 / 判 4 全过） |
| A4 | 开启后：填空题自动填入每空（第一个可接受）答案并锁定 | ✅（`水星` / `义勇军进行曲` / `氮气` 等） |
| A5 | 开启后：题目下方一直显示「正确答案 + 解析」（新反馈块，含 背题模式 标题） | ✅ |
| A6 | 翻上一题/下一题答案**一直保持显示**，无需逐题作答（单/多/判/填 20 题全过） | ✅ |
| A7 | 背题模式下不产生作答/判分/统计/错题痕迹（统计保持 0/20） | ✅ |
| A8 | 已作答过的题不受影响（仍显示正常 ✅/❌ 判分反馈）；关闭开关即恢复常规作答判分 | ✅（判对 1/20 ✅ 回答正确） |
| A9 | 偏好持久化：刷新后模式保持（settings `showAnswer`），筛选摘要行带「· 背题」状态 | ✅ |
| A10 | 默认关闭；全程控制台 0 error | ✅ |

## C. 说明与边界

- 背题模式只作用于「刷题」页签的题目浏览（逐题，配合 上一题/下一题/答题卡跳题 使用）；
  模拟考试按产品定位仍为限时统一判分，不受该开关影响。
- 想“先看题自测、再对答案”时把开关关掉即可；此模式专为快速过题记忆设计。
- 桌面离线版 `dist/考试宝自用版.html` 已是最新；线上需 push 后由 Actions 自动部署。
