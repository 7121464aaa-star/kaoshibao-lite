# M12 验收清单 —— 随机组题（像考试但不是考试 · 进度与刷题互通）

> 日期：2026-09 · 对应 docs/项目进度与交接.md §20 · 角标 M12
> 需求：随机抽一小组题（10/20/30…）来刷，像考试但不是考试；**题型数量可配**（全单选 / 单选X+多选Y…）；做过之后平时刷题的答题卡同步显示（对/错一致），进度互通不因切换清空。

## A. 功能（已实现，本机自动化实测 ✅）

| # | 验收项 | 结果 |
|---|---|---|
| A1 | 刷题「⚙ 筛选」面板底部出现「随机组题」块：单选/多选/判断/填空 各一行 `− 数量 ＋`，旁显“可抽 N”（当前库+章节+练习源范围内） | ✅（单9/多4/判4/填3） |
| A2 | 快捷 chips：10/20/30 题 → 把总数尽量均分到有题的题型（可再手动改）；「清零」清空 | ✅（10→单3多3判2填2；30→全抽20） |
| A3 | 可配“全单选”或混搭：只给某题型填数即可 | ✅（全单选3 题开刷） |
| A4 | 点「🎲 随机抽这组来刷」→ 从当前范围随机抽题组卷、整体打乱，进入普通刷题界面（顶部摘要 `🎲 随机组题 N 题`） | ✅ |
| A5 | 组卷内照常**即时判分**、答题卡 N 格同步绿/红、统计条实时 | ✅（3/3、2/2 均通过） |
| A6 | 做完显示“已刷完这组随机题 N 题 · 对X · 错Y · 正确率Z%（进度已记入平时刷题答题卡）”，按钮为「🎲 再来一组」 | ✅ |
| A7 | **进度互通（核心）**：随机组里做过的题，切回平时刷题「本库全部」后答题卡同格显示绿/红、统计累计 | ✅（随机做 3 题 → 回 20 题卡第3/7/20格绿2红1、3/20；再做 2 题 → 累积 5/20） |
| A8 | 题量不足时提示并全抽（30 题库只有 20 → 全抽 20） | ✅ |
| A9 | 历史记录正确标注 `（🎲 随机组题）` | ✅（3题·对2错1 / 2题·对1错1 两行） |
| A10 | 顶栏「重新开始」仍是清空入口；随机组题里点它=确认后重抽同配置一组（未实点确认弹窗，逻辑走同一入口） | ✅ 代码路径一致 |
| A11 | 控制台 0 error | ✅ |

## B. 用户手机实测（待勾 ✅）

- [ ] PWA 完全关闭再打开，角标显示 M12
- [ ] 刷题 → ⚙ 筛选 → 拉到「随机组题」，点 `10/20/30` 快捷看自动配比，或手动给“单选”填数量做“全单选”
- [ ] 点「🎲 随机抽这组来刷」→ 答题卡出现 N 格、即时对错、统计实时
- [ ] 做完出现“已刷完这组随机题…”提示与「🎲 再来一组」
- [ ] 切回「⚙ 筛选 → 本库全部」：平时刷题答题卡上，刚才做过的题已是绿/红“做过了”，统计累计
- [ ] 顶栏「重新开始」可清空重来（随机组题里是“重抽同配置一组”）

## C. 说明与边界

- 随机组题不设限时、不交卷，判分与界面完全同普通刷题；“像考试但不是考试”。
- 范围 = 当前题库 + 当前章节 + 当前练习源（错题/收藏也支持）；组题不受上方“题型排除”影响。
- 想“回全部列表”继续全量刷：⚙ 筛选 → 点「本库全部」（或其它练习源）即可，进度不丢。
- 桌面离线版 `dist/考试宝自用版.html` 已含 M12。
