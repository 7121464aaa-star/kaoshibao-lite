# M3.1 验收清单：Word(.docx) 直接导入

> 范围（用户拍板）：仅支持 `.docx`；`.xlsx` 留 BACKLOG；老式 `.doc`（二进制）不支持，提示另存 .docx/.txt。
> 实现方式：**零第三方库**——纯前端解析 ZIP（中央目录+局部头）→ 原生 `DecompressionStream('deflate-raw')` 解压
> → DOMParser 读 `word/document.xml` → 还原正文段落/表格文本 → 交给既有"段落文字"解析器识别题型。
> 产物含回归样本生成脚本 `tools/make-docx-sample.ps1` 与样本 `tools/testdata/docx-*.docx`。

## A. 功能清单
- [x] 导入页"载入文件"支持选择 `.docx`（accept 与按钮文案同步更新）
- [x] 载入 .docx → 自动提取正文 → 填入文本框并立即"解析预览"（可先改文字再重新解析）
- [x] ZIP 解析健壮：中央目录定位、局部头取数据偏移、deflate(8) / store(0) 两种压缩方式
- [x] Word 正文还原：w:p 段落（含 w:t/w:tab/w:br）、w:tbl 表格（单元格按行拼接）
- [x] 断题：字面题号（"1. "）与 Word 自动编号段（w:numPr）均可插入空行分隔题目；选项/答案/解析行不会被误断
- [x] 题型识别复用现有解析器：单选/多选/判断/填空全部支持；答案含多选 ABD、判断 对、填空多可接受答案（如 `义勇军进行曲|义勇军军歌`）
- [x] 解析报告：成功数/题型分布/失败明细 + 预览表；可确认导入到新题库或追加已有库
- [x] 错误与边界提示：非 ZIP/缺 document.xml → 明确报错；老式 .doc → 提示另存 .docx/.txt；扫描件/无文字 → 提示
- [x] 顺带修复既有 bug：**段落文字导入中"题号前缀"题干被吞**（`1. 题干` 曾报"题干为空"）—— 现正确剥离题号并保留题干

## D. 已知边界（BACKLOG）
- `.xlsx` 表格导入仍待做（结构不同：需先解析 sharedStrings/单元格坐标）。
- Word 里的题若排版特殊（如题目嵌在表格单元格且一题跨多行表格、图片题干/扫描件），识别率会打折，正文文字可先预览修正。
- 需要较新浏览器支持 `DecompressionStream`（Chrome/Edge 及 Safari 16.4+）；不支持的浏览器会明确提示改走 .txt。
