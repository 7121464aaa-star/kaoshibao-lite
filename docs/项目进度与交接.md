## 1. 项目是什么
考试宝（kaoshibao.com）的自用复刻版：**纯本地 / 无 VIP / 判分必达** 的个人刷题平台。
- 形态：单文件 HTML（双击即用，数据存浏览器 IndexedDB）+ 同一套代码做成 PWA（手机/分屏，GitHub Pages 托管，可安装离线）。
- 范围边界：不抓取考试宝版权题库内容、不破解其服务；数据来自用户自己题库导出/录入。
- 仓库根目录：`E:\浏览器下载\数据\kaoshibao-lite\`
- GitHub 线上仓库（M4 已建）：`https://github.com/7121464aaa-star/kaoshibao-lite`（Pages 地址 `https://7121464aaa-star.github.io/kaoshibao-lite/`）

## 3. 关键决策（用户拍板，勿回退）
1. **判分是硬要求**：练习即时判分、考试交卷统一判分；单选/多选(全对才得分)/判断/填空四种自动判分题型。
2. **轻量化**：简答题（short）与手动"自评"已整体移除（grade/importer/ui/exam/stats/样例/契约全部同步）；导入遇到 short 跳过并提示。
3. **题型过滤**：刷题页 chips（单选/多选/判断/填空）可组合，可与顺序/随机、练习源（全部/错题重练/收藏）叠加。
4. **跨设备**：GitHub 免费账号（PWA 托管 + Secret Gist 一键同步）；冲突策略=后写覆盖+自动快照备份。
5. 记录/历史**永久保留**；题库/收藏/练习配额全部不限（这是去 VIP 的价值）。
6. **M3 起新功能独立页签**：收藏 / 搜题 / 设置（备份恢复）。M4 云同步并入设置页签（非新页签）。
7. **M3 拍板不做**：选项乱序开关、自定义对话框替换 confirm/prompt（记 BACKLOG，勿擅自加入 M3）。
8. **M4 凭据安全（勿回退）**：token/用户名只存本机 IndexedDB settings（键 sync.*）；导出快照剥离 sync.token；拉取/恢复忽略远端 settings（保留本机凭据）；快照与备份永不携带 token。
9. **M4 冲突策略落地**：推/拉覆盖前把"被覆盖方"存为本地自动快照（snapshots store，保留最近 5 份，可一键还原）；一致性判断用业务内容比较（5 个 store），不用 exportedAt。
